# ZackBlock
Customized Blockly  for C# developers.

Online demo: [https://block.youzack.com/](https://block.youzack.com/)

How to run:

This website is a plain and static web application, and this no back-end code involved. What you need to do is to set the folder "ZackBlockFrontEnd" as your website's working directory.

For Microsoft IIS users:

1. Set the folder "ZackBlockFrontEnd" as root directory of your web site.

2. Open the website in your browser.

For other webserver users:

1. Set the folder "ZackBlockFrontEnd" as root directory of your web site.

2. set the following mime-types accordingly:

```
.pdb: application/octet-stream
.blat: application/octet-stream
.dll: application/octet-stream
.dat: application/octet-stream
.json: application/json
.wasm: application/wasm
.woff: application/font-woff
.woff2e: application/font-woff		
```

3.  Open the website in your browser.
